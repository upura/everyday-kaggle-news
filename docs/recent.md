# 最新情報の確認

Kaggle の新機能やコンペ開催などの最新動向を追うための公式発信元、有志コミュニティ、通知ツールをまとめています。

## Kaggle 公式

Kaggle 公式による主な情報発信元です。

- Kaggle 登録メールアドレスへの配信
- [X](https://x.com/kaggle): 公式発表や注目コンペの発信。
- [Official Discord Server](https://www.kaggle.com/discussions/general/429933): Kaggle 公式 Discord サーバの案内。
- [Threads](https://www.threads.net/@officialkaggle): 公式アカウントによる発信。
- [Product Announcements](https://www.kaggle.com/discussions/product-announcements?sort=published): プラットフォームの仕様変更や新機能の公式フォーラム。

## コンペの開催情報

本サイトの[コンペ開催カレンダー](./calendar.md)で、開催中のメダル対象コンペの期間をタイムラインで確認できます（Kaggle API から毎日自動更新）。

[Kaggle 公式のコンペ一覧](https://www.kaggle.com/competitions)でも確認できますが、有志による X（旧 Twitter）の bot も活用できます。

- [Kagoole](https://x.com/kagoole): 新着コンペを通知します。
- [data-compe-alerts](https://x.com/DataCompeAlerts): 開催中のコンペの開催期間を毎日投稿します。

Slack のコミュニティ「[kaggler-ja](https://yutori-datascience.hatenablog.com/entry/2017/08/23/143146)」や Discord サーバ「[かぐるーど](https://scrapbox.io/kaggle-friends/%E3%81%8B%E3%81%90%E3%82%8B%E3%83%BC%E3%81%A9%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6)」でも、コンペの開催情報や解法の議論が行われています。

新着コンペを GitHub Actions で検知してメール通知する[ツール](https://zenn.dev/shoseisan/articles/f6550f488d30be)も公開されています。

## Weekly Kaggle News

Kaggle をはじめとするデータサイエンスコンペの話題を扱う、日本語の非公式ニュースレターです（[バックナンバー一覧](https://weeklykagglenews.substack.com/)）。
毎週金曜日に配信されています。

- [【Weekly Kaggle News 5 周年】記事閲覧数ランキング 2024](https://upura.hatenablog.com/entry/weekly-kaggle-news-5th): 5 年間の配信記事から閲覧数が多かった話題をまとめた振り返り。
- [【Weekly Kaggle News 4 周年】記事閲覧数ランキング 2023](https://upura.hatenablog.com/entry/weekly-kaggle-news-4th): 4 年間の配信記事から閲覧上位の話題を振り返る記事。
- [【Weekly Kaggle News 3 周年】記事閲覧数ランキング 2022](https://upura.hatenablog.com/entry/weekly-kaggle-news-3rd): 3 年間の配信記事から反響の大きかった話題をまとめた記事。
- [【Weekly Kaggle News 2 周年】記事閲覧数ランキング 2021](https://upura.hatenablog.com/entry/weekly-kaggle-news-2nd): 2 周年時点での年間アクセス上位トピックのまとめ。
- [【Weekly Kaggle News 1 周年】記事閲覧数ランキング 2020](https://upura.hatenablog.com/entry/weekly-kaggle-news-1st): 配信初年度のアクセス上位トピックのまとめ。
